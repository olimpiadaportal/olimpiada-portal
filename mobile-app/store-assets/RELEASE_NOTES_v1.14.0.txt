RELEASE NAME  (yalnız Play Console-da görünür, istifadəçiyə YOX)
-----------------------------------------------------------

1.14.0 — Rayonlar, məktəblər və düzəlişlər

  Limit: 50 simvol.


-----------------------------------------------------------
RELEASE NOTES — AZƏRBAYCAN  (az-AZ)
-----------------------------------------------------------

Bu buraxılışda:

• Ölkənin bütün rayonları əlavə edildi — Hacıqabul da daxil. Hər rayon üçün məktəb siyahısı var.
• Şəhər, rayon və məktəb axtarışı: "Haci" yazsanız da "Hacıqabul" tapılır.
• Uşağın 8 rəqəmli nömrəsini toxunmaqla kopyalayın.
• Şifrə yeniləndikdən sonra uşağın daxil ola bilməməsi düzəldildi.
• "ə" hərfinin bəzi telefonlarda boş kvadrat görünməsi düzəldildi.
• Tema dəyişəndə bəzi filtrlərin köhnə rəngdə qalması düzəldildi.
• Fizika artıq yalnız 7-11-ci siniflərə göstərilir.


-----------------------------------------------------------
RELEASE NOTES — ENGLISH  (en-US)
-----------------------------------------------------------

In this release:

• Every district in the country is listed now — Hacıqabul among them — each with its schools.
• Search the city, district and school lists: "Haci" finds "Hacıqabul".
• Tap a child's 8-digit ID to copy it.
• Fixed a password reset that said it worked while the child still could not sign in.
• Fixed the letter "ə" showing as an empty box on some phones.
• Fixed filters keeping old colours after a light/dark switch.
• Physics is now offered only to grades 7-11.


-----------------------------------------------------------
RELEASE NOTES — РУССКИЙ  (ru-RU)
-----------------------------------------------------------

В этом выпуске:

• Добавлены все районы страны, включая Hacıqabul, и для каждого — список школ.
• Поиск по городам, районам и школам: «Haci» найдёт «Hacıqabul».
• 8-значный номер ребёнка копируется одним касанием.
• Исправлен сброс пароля, который сообщал об успехе, но вход не работал.
• Исправлено отображение буквы «ə» пустым квадратом на некоторых телефонах.
• Исправлены фильтры со старым цветом после смены темы.
• Физика теперь доступна только 7-11 классам.
